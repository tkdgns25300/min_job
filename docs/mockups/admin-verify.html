제안 — HEIC·HEIF를 받는 목록에서 뺍니다. 받는 형식은 “운영자가 읽을 수 있는 형식”이어야 합니다. HEIC를 받아 두면 신청자는 올렸는데 운영자가 못 여는 상태가 되고, 결국 반려 → 재신청 한 바퀴를 돌게 됩니다.

아이폰은 대체로 영향이 없습니다 — iOS는 <input type="file">로 올릴 때 HEIC를 JPEG로 바꿔 보냅니다. 영향을 받는 쪽은 주로 맥에서 .heic 파일을 직접 고르는 경우이고, 그때는 “PDF 또는 이미지 파일로 올려 주세요”가 뜹니다.

고칠 곳은 lib/church-verification.ts 한 곳입니다(허용 MIME·확장자·accept가 거기서 파생됩니다). Supabase 버킷의 allowed_mime_types도 맞춰 두면 깔끔하지만, 우리가 먼저 거르므로 필수는 아닙니다.
